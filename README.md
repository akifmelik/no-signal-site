## Quick Publish With GitHub Pages

1. Create a new public repository, for example `no-signal-site`
2. Copy these files into that repo or push this folder as the repo root
3. In GitHub:
   - `Settings`
   - `Pages`
   - `Build and deployment`
   - `Deploy from a branch`
   - choose `main` and `/root`
4. Wait for Pages to publish

If the repo name is `no-signal-site` under the `akifmelik` account, URLs will look like:

- `https://akifmelik.github.io/no-signal-site/`
- `https://akifmelik.github.io/no-signal-site/support.html`
- `https://akifmelik.github.io/no-signal-site/privacy.html`
